# Odin Recipes

This is my submission for The Odin Project's HTML Foundations course — **Project: Recipes**.

## About

A basic multi-page recipe website built with plain HTML to practice:
- Semantic HTML structure (`header`, `main`, `section`, `footer`)
- Linking between multiple pages
- Ordered and unordered lists
- Adding images with descriptive `alt` text
- Organizing a small project into folders (`recipes/`, `images/`)

The site isn't styled yet — CSS comes in a later project. Right now the focus is purely on structuring content with correct, semantic HTML.

## Pages

- `index.html` — the homepage with links to every recipe
- `recipes/spaghetti-carbonara.html`
- `recipes/chicken-tikka-masala.html`
- `recipes/chocolate-chip-cookies.html`
- `recipes/guacamole.html`

## Note on images

The `images/` folder is currently empty. Drop in your own photos named to match the `src` paths in each recipe page (e.g. `images/guacamole.jpg`), or swap in your own filenames and update the `src` attributes accordingly.

## What I practiced

- Setting up a Git repository and pushing it to GitHub
- Writing clean, semantic HTML across multiple linked pages
- Structuring a small project with sensible folders
